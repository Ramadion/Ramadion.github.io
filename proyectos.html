Mini KanBan

Aplicacion web con formato tablero KANBAN para organizacion de tareas

Una plataforma ágil diseñada para optimizar la gestión de equipos, tareas y prioridades en tiempo real. Inspirada en la simplicidad de Trello, esta herramienta eleva la experiencia Kanban tradicional incorporando mejoras clave como el seguimiento avanzado de plazos (deadlines), flujos de trabajo personalizados y un sistema inteligente de notificaciones para mantener a tu equipo siempre alineado.

Gymera

Aplicacion nativa de android (en desarrollo)

Gymera es una aplicacion movil nativa para Android que combina Inteligencia Artificial Generativa (Google Gemini) con una base de datos de ejercicios de dominio publico (free-exercise-db) para ofrecer al usuario rutinas de entrenamiento completamente personalizadas. El usuario responde una serie de preguntas sobre sus caracteristicas fisicas y objetivos, y la IA genera un plan de entrenamiento semanal adaptado a su perfil. Cada ejercicio incluye nombre en espanol, grupo muscular, imagen demostrativa animada y serie/repeticion detallada. La rutina persiste offline via Room y se sincroniza con Firebase Firestore para recuperacion en cualquier dispositivo.
